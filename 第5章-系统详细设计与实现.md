# 第5章 系统详细设计与实现

本章详细介绍房屋租赁信息管理系统各功能模块的设计与实现过程。系统分为租客端和管理端两部分，租客端主要面向普通用户提供房屋浏览、租赁申请、订单查询等功能，管理端主要面向管理员提供用户管理、房屋管理、订单管理、公告管理等后台管理功能。本章重点展示各功能模块的后端关键代码实现。

## 5.1 系统开发环境与架构

### 5.1.1 开发环境

本系统的开发环境配置如下：

| 项目 | 配置 |
|------|------|
| JDK | 11 |
| 数据库 | MySQL 8.x |
| 后端框架 | Spring Boot 2.7.18 |
| 安全框架 | Spring Security + JWT |
| 持久层框架 | MyBatis Plus 3.5.x |
| 构建工具 | Maven |
| 前端框架 | Vue 2.7.14 |
| UI组件库 | Element UI 2.15.14 |
| 开发工具 | IntelliJ IDEA / VS Code |

### 5.1.2 系统架构设计

系统采用经典的MVC分层架构设计，各层职责如下：

**Controller层（控制层）**：负责接收HTTP请求，调用Service层处理业务逻辑，返回统一格式的响应结果。

**Service层（业务逻辑层）**：负责处理具体的业务逻辑，包括数据校验、业务流程处理、事务管理等。

**Mapper层（持久层）**：负责与数据库进行交互，使用MyBatis Plus提供的方法进行CRUD操作。

**Entity层（实体层）**：定义数据库表对应的Java实体类，包含属性和getter/setter方法。

房屋浏览页面是租客登录后的首页，以卡片式布局展示所有上架的房屋信息，用户可以浏览房屋列表、搜索筛选房屋、查看房屋详情。

- 房屋卡片列表：每张卡片展示房屋图片、价格标签、标题、户型、面积、地址、类型标签

**后端接口设计**：房屋浏览页面需要调用后端房屋分页查询接口，获取上架状态的房屋列表数据。

**关键代码示例（后端房屋列表查询接口）**：

**关键代码示例（后端房屋分页查询Service实现）**：

```java
/**
 * 房屋信息Service实现类 - 处理房屋相关业务逻辑
 */
@Service
public class HouseServiceImpl extends ServiceImpl<HouseMapper, House> implements HouseService {

    @Resource
    private HouseTypeService houseTypeService;

    /**
     * 分页查询房屋列表
     * 支持多条件组合筛选：类型、价格区间、状态、关键词
     */
    @Override
    public IPage<House> pageHouse(Long pageNum, Long pageSize, Long typeId,
            BigDecimal minPrice, BigDecimal maxPrice, Integer status, String keyword) {
        
        // 构建查询条件
        LambdaQueryWrapper<House> wrapper = new LambdaQueryWrapper<>();
        
        // 按房屋类型筛选
        if (typeId != null) {
            wrapper.eq(House::getTypeId, typeId);
        }
        
        // 按最低价格筛选（大于等于）
        if (minPrice != null) {
            wrapper.ge(House::getRentPrice, minPrice);
        }
        
        // 按最高价格筛选（小于等于）
        if (maxPrice != null) {
            wrapper.le(House::getRentPrice, maxPrice);
        }
        
        // 按状态筛选（1为上架，0为下架）
        if (status != null) {
            wrapper.eq(House::getStatus, status);
        }
        
        // 按关键词模糊搜索（搜索标题或地址）
        if (StringUtils.hasText(keyword)) {
            wrapper.and(w -> w.like(House::getTitle, keyword)
                    .or().like(House::getAddress, keyword));
        }
        
        // 按创建时间倒序排列（最新发布的在前）
        wrapper.orderByDesc(House::getCreateTime);
        
        // 创建分页对象
        Page<House> page = new Page<>(pageNum, pageSize);
        
        // 执行分页查询
        IPage<House> result = page(page, wrapper);
        
        // 为查询结果填充房屋类型名称
        fillTypeName(result.getRecords());
        return result;
    }

    /**
     * 为房屋列表填充房屋类型名称
     * 避免前端多次查询类型表
     */
    private void fillTypeName(List<House> list) {
        if (list == null || list.isEmpty()) {
            return;
        }
        try {
            // 查询所有房屋类型
            List<HouseType> allTypes = houseTypeService.list();
            // 构建类型ID到类型名称的映射
            Map<Long, String> typeMap = allTypes.stream()
                    .collect(Collectors.toMap(HouseType::getId, HouseType::getName, (a, b) -> a));
            // 为每个房屋设置类型名称
            for (House house : list) {
                if (house.getTypeId() != null && typeMap.containsKey(house.getTypeId())) {
                    house.setTypeName(typeMap.get(house.getTypeId()));
                }
            }
        } catch (Exception e) {
            // 异常时忽略，不影响主流程
        }
    }
}
```

### 5.2.3 申请租赁功能设计

申请租赁功能是租客端的核心功能，用户在浏览房屋后可以提交租赁申请，系统自动处理订单相关逻辑。

**申请流程**：

1. 点击"申请租赁"按钮，弹出申请表单弹窗
2. 表单自动填充房屋信息和月租金（只读展示）
3. 用户选择入住日期（不能早于今天）
4. 用户选择租期（月份数，默认12个月）
5. 用户可填写备注信息（选填）
6. 点击"提交申请"按钮，表单验证通过后调用后端接口
7. 提交成功后提示"申请提交成功，请等待管理员审核"

**后端处理逻辑**：

1. 接收申请数据，校验房屋ID、入住日期、租期等必填参数
2. 查询房屋信息，校验房屋是否存在且状态为上架
3. 自动生成订单编号（ORD+时间戳+随机数）
4. 自动设置订单状态为"待审核"（0）
5. 从当前登录用户信息中获取租客ID、姓名、电话
6. 计算结束日期 = 入住日期 + 租期月数
7. 计算总金额 = 月租金 × 租期月数
8. 保存订单数据到数据库

**关键代码示例（后端租赁申请Controller）**：

```java
/**
 * 租赁订单Controller - 处理订单相关HTTP请求
 */
@RestController
@RequestMapping("/api/order/lease")
public class LeaseOrderController {

    @Resource
    private LeaseOrderService leaseOrderService;

    /**
     * 租客申请租赁
     * 从Spring Security安全上下文中获取当前登录用户信息
     */
    @PostMapping("/apply")
    public Result<Void> apply(@RequestBody LeaseOrder leaseOrder) {
        // 获取当前登录用户信息
        LoginUser loginUser = (LoginUser) SecurityContextHolder.getContext()
                .getAuthentication().getPrincipal();
        SysUser sysUser = loginUser.getSysUser();
        
        // 设置租客信息（从当前用户信息中获取）
        leaseOrder.setTenantId(sysUser.getId());
        leaseOrder.setTenantName(sysUser.getNickname() != null 
                ? sysUser.getNickname() : sysUser.getUsername());
        leaseOrder.setTenantPhone(sysUser.getPhone());
        
        // 调用Service层处理租赁申请
        leaseOrderService.applyOrder(leaseOrder);
        return Result.success();
    }
}
```

**关键代码示例（后端租赁申请Service实现）**：

```java
/**
 * 租赁订单Service实现类 - 处理订单相关业务逻辑
 */
@Service
public class LeaseOrderServiceImpl extends ServiceImpl<LeaseOrderMapper, LeaseOrder> 
        implements LeaseOrderService {

    @Resource
    private HouseService houseService;

    /**
     * 处理租客的租赁申请
     * 核心业务逻辑：校验数据、生成订单、计算金额、保存订单
     */
    @Override
    public void applyOrder(LeaseOrder leaseOrder) {
        // ===== 1. 参数校验 =====
        // 校验房屋ID不能为空
        if (leaseOrder.getHouseId() == null) {
            throw new BusinessException("房屋ID不能为空");
        }
        
        // 校验入住日期不能为空
        if (leaseOrder.getStartDate() == null) {
            throw new BusinessException("入住日期不能为空");
        }
        
        // 校验租期（至少1个月）
        if (leaseOrder.getLeaseMonths() == null || leaseOrder.getLeaseMonths() < 1) {
            throw new BusinessException("租期不能为空");
        }
        
        // ===== 2. 校验房屋信息 =====
        // 查询房屋信息
        House house = houseService.getById(leaseOrder.getHouseId());
        if (house == null) {
            throw new BusinessException("房屋不存在");
        }
        
        // 校验房屋状态（必须为已上架状态，status=1）
        if (house.getStatus() == null || house.getStatus() != 1) {
            throw new BusinessException("房屋未上架，不能申请");
        }
        
        // ===== 3. 生成订单数据 =====
        // 生成唯一订单号：ORD + 时间戳 + 4位随机数
        leaseOrder.setOrderNo(generateOrderNo());
        
        // 设置订单状态为待审核（0）
        leaseOrder.setStatus(0);
        
        // 从房屋信息中获取月租金和押金
        leaseOrder.setMonthRent(house.getRentPrice());
        leaseOrder.setDeposit(house.getDeposit());
        
        // 计算结束日期：入住日期 + 租期月数
        LocalDate endDate = leaseOrder.getStartDate().plusMonths(leaseOrder.getLeaseMonths());
        leaseOrder.setEndDate(endDate);
        
        // 计算总金额：月租金 × 租期月数
        if (house.getRentPrice() != null) {
            leaseOrder.setTotalAmount(house.getRentPrice().multiply(
                    new BigDecimal(leaseOrder.getLeaseMonths())));
        }
        
        // ===== 4. 保存订单 =====
        save(leaseOrder);
    }

    /**
     * 生成唯一订单号
     * 格式：ORD + 年月日时分秒 + 4位随机数
     * 示例：ORD202506291234561234
     */
    private String generateOrderNo() {
        // 生成时间戳
        String timestamp = LocalDateTime.now()
                .format(DateTimeFormatter.ofPattern("yyyyMMddHHmmss"));
        // 生成4位随机数
        Random random = new Random();
        int randomNum = random.nextInt(10000);
        return "ORD" + timestamp + String.format("%04d", randomNum);
    }
}
```

### 5.2.4 我的订单页面设计

我的订单页面展示当前登录用户的所有租赁订单，用户可以了解自己的申请状态和订单详情。

**页面功能**：

- 搜索筛选：支持按订单号搜索、按订单状态筛选

- 订单状态标签：待审核（橙色）、租赁中（绿色）、已到期（灰色）、已取消（红色）
- 订单详情：点击"详情"按钮查看订单完整信息
- 取消订单：待审核状态的订单可以取消

- 租赁中（1）：管理员审核通过，租赁生效中
- 已到期（2）：租赁期限已到
- 已取消（3）：申请被拒绝或租客主动取消

## 5.3 管理端功能的设计与实现

### 5.3.1 后台登录页面设计

后台登录页面是管理员进入系统的入口，采用简洁美观的设计风格。

**登录流程**：

1. 用户输入用户名和密码
2. 点击登录按钮，前端进行表单验证
3. 验证通过后调用后端登录接口
4. 后端验证用户名和密码，验证通过后生成JWT token
5. 前端将token保存到localStorage和Vuex中
6. 跳转到系统首页（仪表盘）
7. 后续请求在请求头中携带token

**后端认证实现**：

```java
/**
 * 认证Controller - 处理登录、退出、获取用户信息等请求
 */
@RestController
@RequestMapping("/api/auth")
public class AuthController {

    @Resource
    private AuthenticationManager authenticationManager;

    @Resource
    private JwtUtils jwtUtils;

    @Resource
    private SysUserRoleMapper sysUserRoleMapper;

    @Resource
    private SysRoleMapper sysRoleMapper;

    /**
     * 用户登录接口
     * 使用Spring Security进行身份认证
     */
    @PostMapping("/login")
    public Result<Map<String, Object>> login(@Validated @RequestBody LoginDTO loginDTO) {
        // ===== 1. 身份认证 =====
        // 创建认证令牌（用户名+密码）
        UsernamePasswordAuthenticationToken authenticationToken =
                new UsernamePasswordAuthenticationToken(
                        loginDTO.getUsername(), 
                        loginDTO.getPassword());
        
        // 调用Spring Security进行认证
        // 如果认证失败会抛出异常
        Authentication authentication = authenticationManager.authenticate(authenticationToken);

        // ===== 2. 获取用户信息 =====
        // 从认证结果中获取登录用户
        LoginUser loginUser = (LoginUser) authentication.getPrincipal();
        SysUser sysUser = loginUser.getSysUser();

        // ===== 3. 生成JWT令牌 =====
        // 使用用户ID和用户名生成token
        String token = jwtUtils.generateToken(sysUser.getId(), sysUser.getUsername());

        // ===== 4. 查询用户角色 =====
        // 根据用户ID查询关联的角色ID列表
        List<Long> roleIds = sysUserRoleMapper.selectList(
                new LambdaQueryWrapper<SysUserRole>()
                        .eq(SysUserRole::getUserId, sysUser.getId())
        ).stream()
         .map(SysUserRole::getRoleId)
         .collect(Collectors.toList());

        // 根据角色ID查询角色信息
        List<String> roleCodes = new java.util.ArrayList<>();
        if (!roleIds.isEmpty()) {
            List<SysRole> roles = sysRoleMapper.selectBatchIds(roleIds);
            roleCodes = roles.stream()
                    .map(SysRole::getCode)
                    .collect(Collectors.toList());
        }

        // ===== 5. 组装返回数据 =====
        Map<String, Object> data = new HashMap<>();
        data.put("token", token);  // JWT令牌
        sysUser.setPassword(null);  // 清除密码，不返回给前端
        data.put("userInfo", sysUser);  // 用户信息
        data.put("roles", roleCodes);  // 角色列表

        return Result.success(data);
    }

    /**
     * 用户退出登录接口
     */
    @PostMapping("/logout")
    public Result<Void> logout() {
        // 清除Spring Security安全上下文
        SecurityContextHolder.clearContext();
        return Result.success();
    }

    /**
     * 获取当前用户信息接口
     */
    @GetMapping("/userInfo")
    public Result<Map<String, Object>> getUserInfo() {
        // 从安全上下文中获取登录用户
        LoginUser loginUser = (LoginUser) SecurityContextHolder.getContext()
                .getAuthentication().getPrincipal();
        SysUser sysUser = loginUser.getSysUser();
        sysUser.setPassword(null);

        }

        Map<String, Object> data = new HashMap<>();
        data.put("userInfo", sysUser);
        data.put("roles", roleCodes);

        return Result.success(data);
    }
```

```java
/**
 * JWT工具类 - 负责令牌的生成、解析、验证
 */
@Component
public class JwtUtils {

    // JWT签名密钥，从配置文件读取
    @Value("${jwt.secret}")
    private String secret;

    // JWT过期时间（毫秒），从配置文件读取
    @Value("${jwt.expiration}")
    private Long expiration;

    /**
     * 根据用户ID和用户名生成JWT令牌
     */
    public String generateToken(Long userId, String username) {
        Map<String, Object> claims = new HashMap<>();
        claims.put("userId", userId);
        claims.put("username", username);
        return createToken(claims, username);
    }

    /**
     * 创建JWT令牌
     */
    private String createToken(Map<String, Object> claims, String subject) {
        Date now = new Date();
        Date expireDate = new Date(now.getTime() + expiration);

        return Jwts.builder()
                .setClaims(claims)          // 设置自定义声明（包含用户ID）
                .setSubject(subject)        // 设置主题（用户名）
                .setIssuedAt(now)           // 设置签发时间
                .setExpiration(expireDate)  // 设置过期时间
                .signWith(SignatureAlgorithm.HS512, secret)  // 使用HS512算法签名
                .compact();
    }

    /**
     * 从令牌中解析Claims
     */
    public Claims getClaimsFromToken(String token) {
        try {
            return Jwts.parser()
                    .setSigningKey(secret)
                    .parseClaimsJws(token)
                    .getBody();
        } catch (Exception e) {
            return null;
        }
    }

    /**
     * 从令牌中获取用户名
     */
    public String getUsernameFromToken(String token) {
        Claims claims = getClaimsFromToken(token);
        return claims != null ? claims.getSubject() : null;
    }

    /**
     * 从令牌中获取用户ID
     */
    public Long getUserIdFromToken(String token) {
        Claims claims = getClaimsFromToken(token);
        return claims != null ? claims.get("userId", Long.class) : null;
    }

    /**
     * 判断令牌是否过期
     */
    public boolean isTokenExpired(String token) {
        Claims claims = getClaimsFromToken(token);
        if (claims == null) {
            return true;
        }
        return claims.getExpiration().before(new Date());
    }
}
```

```java
                    .ge(LeaseOrder::getCreateTime, start)
                    .le(LeaseOrder::getCreateTime, end)
                    .count();
            
            Map<String, Object> item = new HashMap<>();
            item.put("month", month.format(DateTimeFormatter.ofPattern("yyyy-MM")));
            item.put("count", count);
```

```java
        }
        
        // 获取文件原始名称和扩展名
        String originalFilename = file.getOriginalFilename();
        String suffix = originalFilename != null 
                ? originalFilename.substring(originalFilename.lastIndexOf(".")) : "";
        String lowerSuffix = suffix.toLowerCase();
        
        // 校验文件格式
        if (!lowerSuffix.equals(".jpg") && !lowerSuffix.equals(".jpeg") 
            && !lowerSuffix.equals(".png") && !lowerSuffix.equals(".gif")) {
            return Result.error("只支持 jpg、jpeg、png、gif 格式的图片");
        }
        
        // 校验文件大小（不超过5MB）
        long size = file.getSize();
        if (size > 5 * 1024 * 1024) {
            return Result.error("文件大小不能超过 5MB");
        }
        
        // ===== 2. 生成唯一文件名 =====
        String fileName = UUID.randomUUID().toString().replace("-", "") + suffix;
        
        // ===== 3. 创建上传目录 =====
        String uploadDir = System.getProperty("user.dir") 
                + File.separator + "uploads" + File.separator + "house";
        File dir = new File(uploadDir);
        if (!dir.exists()) {
            dir.mkdirs();
        }
        
        // ===== 4. 保存文件 =====
        File destFile = new File(uploadDir + File.separator + fileName);
        file.transferTo(destFile);
        
        // ===== 5. 返回访问URL =====
        String accessUrl = "/files/house/" + fileName;
        return Result.success(accessUrl);
```

- 订单列表：展示所有订单，显示订单号、房屋、租客、月租金、开始/结束日期、状态、创建时间等
- 搜索筛选：按订单号、租客姓名、状态、时间范围等条件搜索
- 订单详情：查看订单的完整信息
- 审核订单：对"待审核"状态的订单进行审核，通过则变为"租赁中"，拒绝则变为"已取消"
- 更新状态：手动更新订单状态（如标记为已到期）
- 删除订单：删除订单记录

**订单状态流转**：

- 租客提交申请 → 待审核（0）
- 管理员审核通过 → 租赁中（1）
- 管理员审核拒绝 → 已取消（3）
- 租客主动取消（待审核状态）→ 已取消（3）
- 租赁到期 → 已到期（2）

```java
/**
 * 租赁订单Service实现类
 */
@Service
public class LeaseOrderServiceImpl extends ServiceImpl<LeaseOrderMapper, LeaseOrder> 
        implements LeaseOrderService {

    @Resource
    private HouseService houseService;

    /**
     * 管理员分页查询订单列表
     */
    @Override
    public IPage<LeaseOrder> pageOrder(Long pageNum, Long pageSize, Integer status,
            LocalDate startTime, LocalDate endTime, String keyword) {
        
        LambdaQueryWrapper<LeaseOrder> wrapper = new LambdaQueryWrapper<>();
        
        // 按状态筛选
        if (status != null) {
            wrapper.eq(LeaseOrder::getStatus, status);
        }
        
        // 按创建时间范围筛选
        if (startTime != null) {
            wrapper.ge(LeaseOrder::getCreateTime, startTime.atStartOfDay());
        }
        if (endTime != null) {
            wrapper.le(LeaseOrder::getCreateTime, endTime.atTime(23, 59, 59));
        }
        
        // 按订单号或租客姓名模糊搜索
        if (StringUtils.hasText(keyword)) {
            wrapper.and(w -> w.like(LeaseOrder::getOrderNo, keyword)
                    .or().like(LeaseOrder::getTenantName, keyword));
        }
        
        // 按创建时间倒序排列
        wrapper.orderByDesc(LeaseOrder::getCreateTime);
        
        // 执行分页查询
        Page<LeaseOrder> page = new Page<>(pageNum, pageSize);
        IPage<LeaseOrder> result = page(page, wrapper);
        
        // 填充房屋标题
        fillHouseTitle(result.getRecords());
        return result;
    }

    /**
     * 查询订单详情
     */
    @Override
    public LeaseOrder getOrderDetail(Long id) {
        LeaseOrder order = getById(id);
        if (order == null) {
            throw new BusinessException("订单不存在");
        }
        fillHouseTitle(java.util.Collections.singletonList(order));
        return order;
    }

    /**
     * 新增订单（管理员使用）
     */
    @Override
    public void addOrder(LeaseOrder leaseOrder) {
        // 生成订单号
        leaseOrder.setOrderNo(generateOrderNo());
        // 默认状态为待审核
        if (leaseOrder.getStatus() == null) {
            leaseOrder.setStatus(0);
        }
        save(leaseOrder);
    }

    /**
     * 修改订单
     */
    @Override
    public void updateOrder(LeaseOrder leaseOrder) {
        if (leaseOrder.getId() == null) {
            throw new BusinessException("订单ID不能为空");
        }
        LeaseOrder existOrder = getById(leaseOrder.getId());
        if (existOrder == null) {
            throw new BusinessException("订单不存在");
        }
        // 不允许修改订单号
        leaseOrder.setOrderNo(null);
        updateById(leaseOrder);
    }

    /**
     * 删除订单
     */
    @Override
    public void deleteOrder(Long id) {
        LeaseOrder order = getById(id);
        if (order == null) {
            throw new BusinessException("订单不存在");
        }
        removeById(id);
    }

    /**
     * 更新订单状态
     * 审核订单、标记到期、取消订单等都通过此方法
     */
    @Override
    public void updateStatus(Long id, Integer status) {
        LeaseOrder order = getById(id);
        if (order == null) {
            throw new BusinessException("订单不存在");
        }
        if (status == null) {
            throw new BusinessException("状态不能为空");
        }
        // 校验状态值范围
        if (status < 0 || status > 3) {
            throw new BusinessException("状态值不正确");
        }
        order.setStatus(status);
        updateById(order);
    }

    /**
     * 生成唯一订单号
     */
    private String generateOrderNo() {
        String timestamp = LocalDateTime.now()
                .format(DateTimeFormatter.ofPattern("yyyyMMddHHmmss"));
        Random random = new Random();
        int randomNum = random.nextInt(10000);
        return "ORD" + timestamp + String.format("%04d", randomNum);
    }
}
```

```java
/**
 * 公告Controller - 处理公告相关请求
 */
@RestController
@RequestMapping("/api/announcement")
public class AnnouncementController {

    @Resource
    private AnnouncementService announcementService;

    /**
     * 分页查询公告列表
     */
    @GetMapping("/page")
    public Result<IPage<Announcement>> page(
            @RequestParam(defaultValue = "1") Long pageNum,
            @RequestParam(defaultValue = "10") Long pageSize,
            @RequestParam(required = false) String keyword,
            @RequestParam(required = false) Integer type,
            @RequestParam(required = false) Integer status) {

                pageNum, pageSize, keyword, type, status);
        return Result.success(page);
    }

     * 获取公告列表（前台展示用）
     */
    @GetMapping("/list")
    public Result<List<Announcement>> list() {
        List<Announcement> list = announcementService.lambdaQuery()
                .eq(Announcement::getStatus, 1)
                .orderByDesc(Announcement::getCreateTime)
                .list();
        return Result.success(list);
    }

    /**
     * 新增公告
     */
    @PostMapping
    public Result<Void> add(@RequestBody Announcement announcement) {
        announcementService.save(announcement);
        return Result.success();
    }

    /**
     * 修改公告
     */
    @PutMapping
    public Result<Void> update(@RequestBody Announcement announcement) {
        if (announcement.getId() == null) {
            return Result.error("公告ID不能为空");
        }
        announcementService.updateById(announcement);
        return Result.success();
    }

    /**
     * 删除公告
     */
    @DeleteMapping("/{id}")
    public Result<Void> delete(@PathVariable Long id) {
        announcementService.removeById(id);
        return Result.success();
    }

    /**
     * 切换公告发布状态
     */
    @PutMapping("/{id}/status")
    public Result<Void> toggleStatus(@PathVariable Long id) {
        Announcement announcement = announcementService.getById(id);
        if (announcement == null) {
            return Result.error("公告不存在");
        }
        // 切换状态：0=下架, 1=发布
        announcement.setStatus(announcement.getStatus() == 1 ? 0 : 1);
        announcementService.updateById(announcement);
        return Result.success();
    }
}
```

## 5.4 本章小结

本章详细介绍了房屋租赁信息管理系统各功能模块的设计与实现过程。租客端实现了房屋浏览、搜索筛选、房屋详情、申请租赁、我的订单、个人中心等核心功能；管理端实现了后台登录、数据仪表盘、用户管理、房屋类型管理、房屋信息管理、租赁订单管理、公告管理等核心功能。

系统后端采用Spring Boot框架进行开发，使用Spring Security + JWT实现身份认证授权，使用MyBatis Plus进行数据持久化操作。各功能模块遵循MVC分层架构原则，Controller层负责接收HTTP请求和参数校验，Service层负责处理业务逻辑和数据校验，Mapper层负责与数据库交互。各模块设计清晰、职责明确、代码复用性好，便于后期的维护和扩展。
